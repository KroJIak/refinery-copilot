# Refinery Copilot · frontend

React 18, TypeScript strict, Vite, Tailwind v4, Zustand и ECharts. Локальная разработка без Docker и backend.

## Запуск

Требуется Node.js 22 LTS или новее и npm. В терминале из папки `frontend`:

```powershell
npm ci
npm run dev:mock
```

Откройте адрес из терминала, по умолчанию http://127.0.0.1:5173. Терминал должен оставаться открытым. Если порт занят предыдущим запуском, остановите его через Ctrl+C либо используйте `npm run dev:mock -- --port 5174`.

`dev:mock` принудительно задаёт `VITE_USE_MOCKS=true`. Значения на экране — детерминированные демонстрационные данные, не показания установки. Все REST-операции и события прогона обслуживаются локальным mock-адаптером.

## Проверки

```powershell
npm run lint
npm run typecheck
npm run build
npx playwright install chromium
npm run test:e2e
```

E2E-проверки сами запускают отдельный dev-сервер на порту 5175.

## Подключение API

Обычный `npm run dev` использует переменные окружения. Скопируйте `.env.local.example` в `.env.local`, установите `VITE_USE_MOCKS=false`. `VITE_API_BASE=/api`, `VITE_PROXY_TARGET=http://localhost:8000`. Поддерживается прежний `BACKEND_URL`.

Vite сохраняет текущую схему backend: браузер запрашивает `/api/...`, прокси удаляет префикс `/api` перед передачей серверу с `root_path=/api`.

Страницы используют только Zustand-стор; единый клиент переключает mock/live на уровне транспорта. DTO — ручные зеркала `docs/api/`; до появления полного OpenAPI бэкенда автоматический кодоген не подменяется фиктивным файлом. Каталог сценариев и описания управляемых параметров имеют черновой контракт из `testing/MVPv0`, который потребуется сверить при интеграции.

## Экраны

- `/` — выбор архивного пресета и запуск рекомендации.
- `/recommendation` и `/recommendation/:runId` — ход прогона, совет или отказ, история и экспорт.
- `/whatif` — модельная оценка изменения управляемых параметров.
- `/mnemonic` — схема установки с датчиками.
- `/models` — паспорта и метрики моделей.
- `/data` — свежесть источников, проблемные теги и покрытие.

Mock-модель what-if иллюстрирует поведение интерфейса; её расчёты не являются промышленной моделью. Пороговые значения и численные данные хранятся в фикстурах, а не в JSX.
